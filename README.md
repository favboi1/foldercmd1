# Python Port Scanner

A simple Python-based port scanner created for learning networking and cybersecurity fundamentals.

## Features
- Scans ports 1–1024
- Detects open ports
- Beginner-friendly cybersecurity project

## Technologies Used
- Python
- Socket Library

## Purpose
This project was built to improve my understanding of:
- Networking
- Ports and services
- Cybersecurity basics
- SOC analyst fundamentals

## How To Run

```bash
python scanner.py
